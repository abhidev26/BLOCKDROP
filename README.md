
# 🧱 BLOCKDROP

### A Modern Browser-Based Block Puzzle Game

BLOCKDROP is a browser-based block puzzle game built with HTML, CSS, and JavaScript. The project focuses on interactive gameplay, responsive design, player progression, and a customizable gaming experience.

## 🎮 Project Overview

- **Project:** BLOCKDROP
- **Type:** Browser-based puzzle game
- **Frontend:** HTML5, CSS3, JavaScript
- **Storage:** Browser Local Storage for supported preferences and progress
- **Status:** Portfolio project in development

## ✨ Features

The project roadmap includes the following features. Availability depends on which modules are connected to the main game engine.

- Classic block puzzle gameplay
- Multiple game modes and difficulty options
- Player statistics and progression
- Achievements and leaderboard
- Daily challenges
- Power-ups and special blocks
- Combo and streak system
- Customizable game themes
- Visual effects and animations
- Sound preferences
- Accessibility settings:
  - High-contrast mode
  - Larger text
  - Reduced motion
- Responsive user interface

## 🚀 Getting Started

### Requirements

- A modern web browser
- Git (optional)
- Visual Studio Code (recommended)

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/gowdaabhishek40641-jpg/BLOCKDROP.git
   ```

2. Open the project folder:

   ```bash
   cd BLOCKDROP
   ```

3. Open the folder in Visual Studio Code.

4. Open `index.html` in your browser, or use the VS Code Live Server extension.

If your project uses JavaScript modules or other server-dependent features, run it through a local development server instead of opening the file directly.

## ♿ Accessibility

BLOCKDROP includes an accessibility-settings module designed to support:

- Improved contrast
- Larger interface text
- Reduced CSS motion
- Saved user preferences

Some accessibility features may require integration with existing game components before they affect every part of the game.

## 🧪 Testing Checklist

Before publishing a release, verify:

- [ ] The game loads without console errors.
- [ ] Core gameplay works from start to game over.
- [ ] Keyboard controls work as intended.
- [ ] Game mode and difficulty selections work.
- [ ] Scores and statistics update correctly.
- [ ] Settings persist after refreshing.
- [ ] Sound controls affect actual audio playback.
- [ ] Reduced motion affects decorative animations.
- [ ] The interface works on desktop and mobile.
- [ ] No buttons or navigation controls are broken.
